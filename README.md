> **Paper:** A Comparative Analysis of Code Quality Generated by ChatGPT (GPT-4o),
> Claude (3.5 Sonnet), and GitHub Copilot Using Software Engineering Metrics  
> **Authors:** Syakira Putri Zahara · Raphael Aditya Isworo · Nikita Ananda Putri Masaling · Edy Irwansyah

## Overview

This repository contains all experimental artifacts for a controlled empirical
study that evaluates Python code generated by three AI tools across four software
engineering quality metrics:

| Metric | Operationalization |
|---|---|
| **Functional Correctness** | pytest pass rate (≥ 10 test cases per task) |
| **Code Readability** | pylint (0–10) + manual PEP 8 rubric (1–5, Cohen's κ ≥ 0.61) |
| **Efficiency** | timeit runtime (ms, 1 000 iterations) + manual Big-O classification |
| **Maintainability** | radon Cyclomatic Complexity (CC) + pylint duplication detection |

Results are aggregated into a **Composite Quality Score (CQS)** (equal 25% weighting)
with sensitivity analysis available in `results/summary/cqs_results.csv`.

## Quick Start

### 1. Clone and install dependencies

```bash
git clone https://github.com/spzhrrr/Paper-RM-ai-code-quality-evaluation
cd Paper-RM-ai-code-quality-evaluation
pip install -r requirements.txt
```

### 2. Run unit tests against a specific model

```bash
# Test Claude's solutions (default)
pytest tests/test_cases.py -v

# Test ChatGPT's solutions
MODEL=chatgpt pytest tests/test_cases.py -v

# Test Copilot's solutions
MODEL=copilot pytest tests/test_cases.py -v
```

### 3. Run unit tests against a single task

```bash
MODEL=claude pytest tests/test_cases.py::TestT01_IsPrime -v
```

### 4. Run the full evaluation pipeline

```bash
python scripts/evaluate.py --verbose
```

This re-generates `results/summary/metrics.csv` and `results/summary/cqs_results.csv`
from the solution files.

### 5. Inspect pre-collected raw outputs

Raw tool outputs from the original experiment are archived in `results/raw/`.
These reflect the actual evaluation environment (see `docs/session_protocol.md`).

## Models and Access Configuration

| Model | Version | Interface |
|---|---|---|
| ChatGPT | GPT-4o | chat.openai.com — single-turn, fresh session per task |
| Claude | 3.5 Sonnet | claude.ai — fresh session per task |
| GitHub Copilot | VS Code v1.89+ | **Copilot Chat panel only** — fresh window, no open files |

> **Why Copilot Chat?** Copilot's inline suggestion mode responds to surrounding
> editor context and cannot be held constant across models. Using Copilot Chat
> with the same prompt text ensures prompt equivalence. See `docs/session_protocol.md §2.3`.

All sessions were conducted on **2025-04-01**.

## Key Results (Summary)

| Model | FC | CR | EF | MA | **CQS** |
|---|---|---|---|---|---|
| Claude (3.5 Sonnet) | 1.000 | 0.891 | 1.000 | 1.000 | **0.973** |
| ChatGPT (GPT-4o) | 0.970 | 0.745 | 0.440 | 0.750 | **0.726** |
| GitHub Copilot | 0.970 | 0.635 | 0.070 | 0.667 | **0.585** |

*FC = Functional Correctness, CR = Readability, EF = Efficiency, MA = Maintainability (all normalized 0–1)*

Sensitivity analysis confirms this rank ordering is stable across all 16
weight variation scenarios tested. Full results: `results/summary/cqs_results.csv`.

## Reproducibility Notes

- All prompts, unit tests, and rubric criteria were **locked before any code
  generation began** (see `docs/session_protocol.md §1`).
- The best-of-3 selection protocol introduces **optimistic bias** in correctness
  scores. See `docs/limitations.md §2` for full discussion.
- Proprietary model backends cannot be guaranteed to reproduce identical outputs
  if re-queried after 2025-04-01. All generated outputs are archived verbatim
  in `solutions/` and `data/raw_outputs.json`.
